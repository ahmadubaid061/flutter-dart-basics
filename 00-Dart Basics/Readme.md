# Dart Basics

Beginner-level Dart programs covering the core language fundamentals.

## Contents

| File | Topic |
|---|---|
| `00-Dart-Variables.dart` | Variables and data types |
| `01-Dart-Conditional-Statements.dart` | If/else and conditional logic |
| `02-Loops_in_Dart.dart` | For, while, and do-while loops |
| `03-Lists_Operations.dart` | Creating and manipulating lists |
| `04-Looping-through-List.dart` | Iterating over lists |
| `05-Functions-in-Dart.dart` | Defining and calling functions |

## How to Run

```bash
dart run <filename>.dart
```

Example:

```bash
dart run 00-Dart-Variables.dart
```
